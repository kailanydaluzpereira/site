Componentes Internos

CPU

A CPU (Unidade Central de Processamento) é o cérebro do computador, responsável por processar as informações e executar as instruções dos programas.

Armazenamento

Os dispositivos de armazenamento são responsáveis por guardar dados permanentemente, como HDs e SSDs.

Memória

A memória RAM armazena temporariamente dados e instruções enquanto o computador está em uso.

Fonte de Alimentação

Transforma a energia elétrica da tomada em níveis adequados para o funcionamento dos componentes internos.

Componentes Externos

Teclado

Dispositivo de entrada usado para digitar informações.

Monitor de Vídeo

Dispositivo de saída que exibe imagens e informações do computador.

Mouse

Dispositivo apontador que permite a interação com a interface gráfica do computador.

Interfaces de Entrada e Saída

HDMI

Interface de alta definição usada para transmissão de áudio e vídeo digital.

USB

Padrão universal de conexão para dispositivos como pendrives, teclados, mouses, entre outros.

Grandezas Elétricas

Potência Elétrica

Representa a quantidade de energia elétrica convertida por unidade de tempo.

Tensão Elétrica

Também chamada de voltagem, representa a diferença de potencial elétrico entre dois pontos de um circuito.

Corrente Elétrica

É o fluxo de elétrons através de um condutor.
